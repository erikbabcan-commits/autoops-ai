Transparent PWA icon export

Recommended:
- Use the `glow/` folder if you want the neon aura preserved with transparency.
- Use the `clean/` folder if you want only the cut-out glyph.
- For manifest icons, copy the files you need into `/public/icons/`.

Do not mark these transparent icons as `maskable` unless you intentionally want unpredictable cropping.
For a proper maskable PWA icon, create a separate icon with an opaque safe-zone background.
